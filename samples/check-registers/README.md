# Sample check registers

Committed CSV files for the demo customers. They are not generated by the API.

`make seed` loads two of them onto the register:

| File | Loaded by seed | Customer | Account number | Checks | Rows |
|------|----------------|----------|----------------|--------|------|
| `acme-treasury.csv` | yes | Acme Treasury | `100200301` | 20000 through 20259 | 260 |
| `beta-operating.csv` | yes | Beta LLC | `900100` | 30000 through 30339 | 340 |
| `acme-operating.csv` | no, upload it | Acme Corp | `100200300` | 10000 through 10299 | 300 |

Acme Corp already has checks `1001` through `1006` from `scripts/seed.sql` for the decide examples. `acme-operating.csv` does not overlap those numbers. Upload it with Postman or:

```bash
curl -s -F file=@samples/check-registers/acme-operating.csv \
  localhost:8080/v1/fis/11111111-1111-1111-1111-111111111111/parties/bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbbbbbb/check-registers
```

| | Institution | Routing number | Party id |
|--|-------------|----------------|----------|
| Acme Corp and Acme Treasury | First Demo Bank `11111111-1111-1111-1111-111111111111` | `011000015` | Corp `bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbbbbbb`, Treasury `cccccccc-cccc-cccc-cccc-cccccccccccc` |
| Beta LLC | Second Demo CU `aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaaa` | `211274450` | `dddddddd-dddd-dddd-dddd-dddddddddddd` |

`Smith, Jones & Co` is in each file so a payee comma is quoted. To rewrite the files from the script under `scripts/gen-sample-registers`:

```bash
go run ./scripts/gen-sample-registers
```
